# ระบบร่างหนังสือราชการและพิมพ์เอกสาร (Web-based Official Document Drafting & Print System)

ระบบสำหรับจัดทำหนังสือราชการผ่านเว็บเบราว์เซอร์ พร้อมระบบจัดหน้ากระดาษ A4 และสั่งพิมพ์/บันทึก PDF ตามระเบียบสำนักนายกรัฐมนตรีว่าด้วยงานสารบรรณ พ.ศ. ๒๕๒๖ (อ้างอิง `03.pdf`, `rabeab.md`, `in01.pdf`, `exam01.pdf`, `exam02.pdf`)

---

## 🚀 วิธีใช้งานและทดสอบระบบ

### ทางเลือกที่ 1: รันผ่าน Web Application เต็มรูปแบบ (Vite + React)
```bash
# 1. เข้าสู่โฟลเดอร์ apps/web
cd sarabun-system/apps/web

# 2. รันโหมด Development
npm run dev
# เปิดเบราว์เซอร์ที่ http://localhost:3000
```

### ทางเลือกที่ 2: เปิดใช้งานทันทีโดยไม่ต้องติดตั้งโปรแกรม (Zero Install)
เปิดไฟล์ `prototype/memo-print.html` ใน Google Chrome, Edge หรือเบราว์เซอร์ใดๆ ได้ทันที:
* มาพร้อม **ตราครุฑเวกเตอร์ SVG มาตรฐานราชการ** ความละเอียดสูง
* ฟอนต์ TH Sarabun New ฝังในตัว
* สลับประเภท "บันทึกข้อความ" และ "หนังสือภายนอก"
* พิมพ์ตรงลงกระดาษ A4 หรือบันทึกเป็น PDF ได้ทันที

## 📌 ฟีเจอร์ที่พัฒนาแล้ว

- [x] **ตราครุฑราชการไทย (Official Thai Garuda Vector SVG)**:
  - ขนาด 3 ซม. จัดกึ่งกลางสำหรับ **หนังสือภายนอก**
  - ขนาด 1.8 ซม. ชิดมุมซ้ายบนสำหรับ **บันทึกข้อความ**
- [x] **ระบบจัดหน้ากระดาษ A4 (A4 Print Engine)**:
  - ขนาด 210 × 297 มม.
  - ขอบบน 2.5 ซม. / ขอบซ้าย 3 ซม. / ขอบขวา 2 ซม. / ขอบล่าง 2 ซม.
  - ชดเชยระยะกึ่งกลางจริง (`--center-fix: -0.5cm`)
  - ฟอนต์ TH Sarabun New 16pt พร้อมระยะบรรทัด 1 เท่า (Single)
  - ระบบย่อหน้า 2.5 ซม. อัตโนมัติทุกย่อหน้า
- [x] **ตัวแก้ไขเอกสาร (Document Editor)**:
  - ฟอร์มข้อมูลตามประเภทหนังสือราชการ
  - แถบเครื่องมือช่วยพิมพ์: ขึ้นย่อหน้าใหม่, แทรกรายการ, แทรกตารางรายการทางการ
  - เครื่องมือ **แปลงเลขอารบิก (0-9) เป็นเลขไทย (๐-๙)** ในคลิกเดียว
  - ระบบบันทึกร่างอัตโนมัติ (Autosave to LocalStorage)
  - ปุ่มโหลดตัวอย่างจริง (อบจ.ปราจีนบุรี / สำนักนายกรัฐมนตรี)
- [x] **Live A4 WYSIWYG Preview**:
  - แสดงตัวอย่างเอกสารแบบเรียลไทม์ควบคู่ขณะพิมพ์
  - แถบปรับซูม (Zoom 50% - 140%)
  - ตัวเลือกแสดงเส้นวัดขอบกระดาษ (Margins Guide)
- [x] **สั่งพิมพ์และบันทึก PDF (Print / PDF)**:
  - ใช้ `@media print` ซ่อน UI ทั้งหมด เหลือเฉพาะแผ่นกระดาษ A4 ที่คมชัดทุกรายละเอียด
